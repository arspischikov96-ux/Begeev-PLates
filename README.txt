1) Создайте на github.com новый репозиторий (Add file -> Upload files) и загрузите ВСЁ содержимое этой папки (включая скрытую папку .github).
2) Откройте вкладку Actions -> "Build APK" -> дождитесь зелёной галочки (2-4 мин).
3) Откройте запуск -> внизу Artifacts -> Begeev-Nomera-apk -> скачайте, распакуйте zip, установите .apk на телефон.
